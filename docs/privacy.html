Privacy Policy

Application: WhatsApp Google Classroom Assistant
Last updated: October 27, 2026

Who is responsible

This is a personal, non-commercial application developed and operated by an individual developer, listed on GitHub as 1CE-XD ("the operator"). Contact: open an issue at the GitHub issue tracker.

What Google data the application accesses

The application connects to Google with a single Google account (the operator's own) and uses read-only access only:

  • Google Classroom: course lists, announcements, coursework (assignments) and due dates, coursework materials, and student submissions visible to that account.
  • Google Drive (read-only): only to download files that are shared through Classroom when such a file is explicitly requested in a chat.

Google never receives write access through this application — it cannot create, modify or delete anything in Classroom or Drive.

How the data is used and shared

  • Summaries of new Classroom posts and deadline reminders are posted into the specific WhatsApp groups that the operator configured.
  • When a chat member explicitly requests it (for example with a command such as !get), Classroom files are downloaded and delivered into that chat; the requester can choose delivery as a private (direct) WhatsApp message.
  • AI features: when the assistant is used, a limited buffer of recent chat messages may be sent to Google's Gemini API to generate summaries or answers. AI conversation history is kept locally and capped in size.
  • Nothing is sold, rented or used for advertising. No analytics or trackers are used anywhere.

Where data is stored

  • Everything lives locally on the operator's own computer: the Google OAuth token (token.json), short rolling chat memory buffers used for summaries, capped AI conversation history, and small settings/state files.
  • The application has no separate server infrastructure. This website is fully static: no cookies, no analytics, no logins.
  • Messages and media sent through WhatsApp are processed by WhatsApp (Meta) under their own terms and policies; Google data is processed by Google under its terms and policies.

How long data is kept

Chat memory buffers keep roughly the last 100 messages per group and the AI history only the last few exchanges; older items are automatically overwritten. The OAuth token and settings persist until revoked or deleted.

Your controls

  • Revoke Google access at any time at myaccount.google.com/permissions — the connection stops immediately.
  • Leave a WhatsApp group, or ask the operator to stop syncing a group.
  • Data requests (export, correction, deletion): open an issue at the GitHub issue tracker above.
  • Deleting the local token and memory files removes all locally stored data.
